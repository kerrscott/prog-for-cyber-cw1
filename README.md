This Python script demonstrates basic dictionary manipulation using a mock security event log. It starts by printing specific details like the username and IP address, then updates the risk level, adds a new status field, and deletes the event type before looping through and counting the remaining key-value pairs.

How to run: Security Event Dictionary Manipulation

1. Navigate to the project folder in your terminal and run the script:
   ```bash
   python3 event_dict.py
   ```
2. View Output: No user input is required. The script will automatically print the initial username and IP address, display the updated key-value pairs after modifying and deleting fields, and show the final count (`4 Key Value Pairs`).
